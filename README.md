# Otom David — Portfolio

Personal portfolio and project showcase, built as a static site.

**Live:** https://otomdev.vercel.app

## About

Software engineer working at the boundary between large language models and
deterministic software — research, mobile development, and applied
engineering across freelance, personal, and early-stage startup work.
Independent author of *A Validated Semantic Boundary Between Natural Language
and Database Execution* (Zenodo, 2026).

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

## Structure

All site content (identity, projects, skills) is centralized in
`src/lib/portfolio.ts` — update that file to change what the site displays
rather than editing individual section components.
